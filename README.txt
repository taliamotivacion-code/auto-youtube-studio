AUTO YOUTUBE STUDIO — Mobile starter

This is an installable PWA starter, not a signed APK.
To install on Android:
1. Upload the folder contents to HTTPS static hosting (for example GitHub Pages or Netlify).
2. Open the HTTPS address in Chrome on Android.
3. Chrome menu (three dots) > Install app / Add to Home screen.
4. Paste script, open TalkTTS.io, generate and download voiceover, then import audio and images.
5. Tap Create Video and download WebM.

Limitations: TalkTTS is opened as an external site; there is no direct API integration. Browser export is WebM, not MP4. Keep the screen awake while rendering. Large projects may exceed mobile memory limits. A signed native APK requires Android SDK/build tooling and testing.
